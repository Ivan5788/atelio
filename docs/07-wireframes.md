## 2. 工作坊列表 `/workshops`（搜尋與篩選）

```text
D ┌───────────────────────────────────────────────────────────────┐
  │ 首頁 / 探索工作坊                                                 │
  │ H1 探索工作坊                                                    │
  │ [🔍 關鍵字……………………………]   共 86 堂   排序：[即將開課 ▾]   [▦][☰]     │
  ├──────────────┬────────────────────────────────────────────────┤
  │ 篩選  清除全部  │ 已選：[陶藝 ×] [台北 ×]                            │
  │              │                                                │
  │ 分類          │  [Card] [Card] [Card]                           │
  │ ☑ 陶藝 (18)   │  [Card] [Card] [Card]                           │
  │ ☐ 皮革 (11)   │  [Card] [Card] [Card]                           │
  │ 城市          │                                                │
  │ ◉ 台北        │                                                │
  │ 價格          │                                                │
  │ [800]—[3000]  │                                                │
  │ 難度          │         ‹ 1 2 [3] 4 … 8 ›                        │
  │ ☐新手 ☐進階    │                                                │
  │ 日期          │                                                │
  │ [起] [迄]     │                                                │
  └──────────────┴────────────────────────────────────────────────┘
```
- 篩選條件改變 → 更新 URL query → 重新取得資料（可分享、可上一頁返回）。
- 關鍵字輸入防抖動（debounce 300ms）。
- 載入中：保留舊結果並降低透明度＋頂部進度條；首次載入顯示 Skeleton 卡片。
- 無結果：Empty State「找不到符合的工作坊」＋[清除篩選]＋熱門分類。
- **T**：Sidebar 收合為頂部的「篩選」按鈕，開啟側邊抽屜（Drawer）。
- **M**：篩選為全螢幕抽屜，底部固定 [清除] [顯示 32 個結果]；排序為獨立下拉；分頁簡化。

## 10. RWD 檢查清單（Phase 6 實際測試）

| 項目 | M | T | D |
| --- | --- | --- | --- |
| 無水平捲軸（320px 寬度起） | ☐ | ☐ | ☐ |
| 點擊區域 ≥ 44px | ☐ | ☐ | — |
| 導覽可用（☰ 選單 / 完整導覽） | ☐ | ☐ | ☐ |
| 篩選抽屜可開關、可用鍵盤 | ☐ | ☐ | — |
| 表格在手機改為卡片 | ☐ | — | — |
| 底部固定列不遮擋內容 | ☐ | — | — |
| 圖片依尺寸載入適當解析度 | ☐ | ☐ | ☐ |
| 橫向（landscape）手機可正常操作 | ☐ | — | — |

測試尺寸：320、375、414（手機）、768、834（平板）、1024、1280、1440（桌機）。
